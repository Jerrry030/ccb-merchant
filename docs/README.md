## 文档维护方式

- README 负责定位、快速开始和导航，不复制完整配置表或业务操作细节。
- 每项规则只在负责它的指南中完整维护，其他页面链接到该指南。新增文档同时更新本索引。
- 行为说明以实现和回归测试为依据。修改接口、参数、持久化文件或构建输入时，同步相关指南及发布清单。
- 指南描述“怎么做”，发布记录描述“这次实际做了什么”。没有执行的检查标为未验证，不沿用历史通过结论。
- 对外记录只保留提交、工具版本、测试范围及脱敏结果。真实配置、客户资料、日志、备份和证据原件保存在仓库外受保护位置。
- 命令注明工作目录和 Shell；使用相对项目路径及占位值，不写入个人机器路径、真实域名或密钥。
