# 管理员日常业务

本页描述本站管理员的处理入口，不涉及提供方后台，也不授权任何真实收款、退款或部署。

## 待办

- 待确认支付包括创建中、待支付、结果未知；点击卡片进入同一组状态的支付订单。
- 待核对交付包括待核对交付和退款核对中；点击卡片或处理入口都进入完整异常集合。
- 列表可按客户姓名、邮箱或订单编号查询；交付订单还可按套餐名查询。
- 核对支付仍依赖服务端查单。退回余额仍不等于支付渠道原路退款。

## 客户

从客户列表的「客户详情」进入。页内分区是概览、账号、设备、用量、订单和审计；订单再分交付和支付。标题、面包屑和侧栏保持在这位客户上。返回客户列表时保留原来的搜索和分页位置。

各数据区独立处理读取失败，未知不等于零或没有记录。概览里的最近订单和失败请求最多显示 5 条，完整记录从对应分区查询。

## 库存与续期

- 搜索账号名称、授权编号、客户姓名或邮箱；高级筛选包含平台、状态、到期口径、7/30 天范围和排序。
- 客户到期与上游授权到期是不同口径。未提供对应期限的记录不进入临期结果，排序时放在有效日期后。
- 当前/历史区分以及统计范围沿用库存规则；筛选无结果不代表整个库存为空。
- 续期支持延长 7/30 天，按 24 小时计一天，从当前时间与原客户期限中较晚者起算。超出上游授权期限的快捷项禁用；提交前再次展示客户、账号、原期限和新期限。
- 写入仍携带所见授权版本；冲突或结果未知不能当作成功，也不自动重放。

## 审计查询

可按人员/目标、业务操作、结果、时间或客户范围筛选并分页。技术标识可展开复制；查询不再只截取最近 500 条。

新授权操作记录关联客户和当时的账号名称。历史记录保持不可修改，只按已有本地关系解析；无法确定的客户显示未关联，不根据操作者推测归属。操作者和客户姓名按当前资料展示。

数据库启动时仅为审计表补充可空字段和查询索引，不删除、回填或改写历史审计，现有不可更新/不可删除约束保持不变。

## 验证范围

HTTP 和浏览器回归使用隔离 SQLite、合成客户和本机提供方夹具。结果不代表真实提供方、真实支付、生产部署或用户验收。


## 本店账号编号

库存为每个授权占用持久化分配本店编号（如“账号#1”），客户账号、设备选择、分配确认和新审计使用相同编号。编号不由邮箱、真实账号名或上游 UUID 截取得到。分组显示名来自公开资源目录，不能拿原账号名当作分组名回显。

同一授权记录刷新、重启、分配或收回不会重新编号；不同授权占用不因名称相同而合并。上游未提供跨授权周期稳定账号标识，因此新授权可能得到新编号，不能据此声称识别了同一个底层账号。编号表应随运行数据库成套备份。

## 额度与可分配状态

库存列表显示额度窗口、重置时间与快照更新时间，详情保留所有返回窗口。缺测显示未知，不把缺失百分比转成 0%；失败和超过 15 分钟的快照明确提示。刷新页面读取提供方快照，不承诺主动更新提供方额度。

未明确允许转授、状态未就绪、期限未知、已有支付占用或分配结果待核对的账号，不进入可分配集合。服务器提交时再次校验；不能只依赖页面按钮状态。

## 批量分配

在库存按当前筛选勾选账号（每批最多 100 个），选择统一客户或逐项指定客户，核对每项期限，先预检再确认。客户选择支持搜索和分页，已明确指定的客户不会因不在第一页而丢失。

单条/批量 UI 都使用持久化分配批次；执行复用同一账号交付实现。分配结果分为未执行、执行中、已成功、明确失败、结果待核对和已取消。批次意图保存后不可修改：

- 继续只处理未执行项，成功项不会重放。
- 核对未知项只读取账号状态，不发送新的交付请求。不能确认时继续保留占用。
- 明确失败项可以从“为失败项新建分配”修正后生成新批次，不混入已成功项。
- 取消只取消未执行项，不收回成功项，也不释放未知项。
- 进程中断时执行中项目转为待核对，不自动执行；其他项目须管理员显式继续。
- 批次可分页查询、导出结果。库存不可读取时，已保存的批次记录仍可查看。

库存表每页展示 50 条；提供方集合仍由后端按当前公开分页合同完整读取，不宣称实现了提供方侧库存筛选或跨页多选。

## 客户资料与登录安全

客户资料编辑携带所见 revision；过期表单被拒绝，不覆盖另一管理员的更新。支持备注、标签、角色/状态/标签/账号情况/临期筛选和当前页导出。备注、标签不进入客户会话数据或上游同步。

邮箱纠错需要管理员当前密码和原因。启用邮箱验证时，先发送验证到新邮箱，验证前保留旧登录邮箱；没有可用邮件服务时不能绕过验证。未启用邮箱验证时由管理员确认后修改，撤销旧网页登录会话。始终保留原客户身份映射。

客户详情的“登录安全 / 重置密码”提供：

- 设置临时密码：撤销旧网页登录会话与认证令牌；客户登录后只能更改密码、退出或读取会话，完成更改后重新登录。
- 发送重置邮件：需可用邮件服务，不把发送结果未知写成已送达。
- 退出所有网页登录会话：独立于账号停用，不自动撤销运行设备。

这些操作要求管理员当前密码、客户版本和处理原因，有权限及频率限制。密码和重置令牌不写入审计。管理员修改自己的密码仍使用个人设置；不能通过客户安全操作绕开自己的改密流程。

## 管理权限分工

保留 admin/member 身份模型，在管理员上设置管理权限配置：站点管理员、客服、运营、财务、只读审计。

- 站点管理员：完整本站管理，至少保留一位有效站点管理员。
- 客服：客户资料、成员登录安全与设备协助；不能管理其他管理员或站点设置。
- 运营：客户创建/资料、设备和账号分配；不能提升角色或修改站点设置。
- 财务：订单、交付核对、套餐；不能分配账号或重置密码。
- 只读审计：允许的业务读取，不允许写入。

非站点管理员不能读取上游/邮件/支付密钥配置或 API 客户凭据管理。权限在服务端重查；界面提示或隐藏入口不能替代鉴权。原有管理员保持原来的完整权限，不自动降权。

## 仍有明确边界

原路退款、换号补偿和主动更新上游额度，需要提供方/渠道能力和业务规则，不用假付款或直接改账本代替。新功能通过隔离测试不等于真实提供方或真实支付验收。
