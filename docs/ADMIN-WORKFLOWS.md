# 管理员日常业务

本页描述本站管理员的处理入口，不涉及提供方后台，也不授权任何真实收款、退款或部署。

## 运营待办

- 待确认支付包括创建中、待支付、结果未知；点击卡片进入同一组状态的支付订单。
- 待核对交付包括待核对交付和退款核对中；点击卡片或处理入口都进入完整异常集合。
- 列表可按客户姓名、邮箱或订单编号查询；交付订单还可按套餐名查询。
- 核对支付仍依赖服务端查单。退回余额仍不等于支付渠道原路退款。

## 客户详情

从客户管理的「客户详情」进入，集中查看当前账号、客户期限、设备、最近交付、最近支付和近 7 天失败请求。

相关页面保留当前客户与返回详情的入口；从详情返回客户列表时保留原搜索和分页位置。各数据区独立处理读取失败，未知不等于零或没有记录。最近订单和失败请求仅展示最多 5 条，完整记录从相应入口查询。

## 库存与续期

- 搜索账号名称、授权编号、客户姓名或邮箱；高级筛选包含平台、状态、到期口径、7/30 天范围和排序。
- 客户到期与上游授权到期是不同口径。未提供对应期限的记录不进入临期结果，排序时放在有效日期后。
- 当前/历史区分以及统计范围沿用库存规则；筛选无结果不代表整个库存为空。
- 续期支持延长 7/30 天，按 24 小时计一天，从当前时间与原客户期限中较晚者起算。超出上游授权期限的快捷项禁用；提交前再次展示客户、账号、原期限和新期限。
- 写入仍携带所见授权版本；冲突或结果未知不能当作成功，也不自动重放。

## 审计查询

可按人员/目标、业务操作、结果、时间或客户范围筛选并分页。技术标识可展开复制；查询不再只截取最近 500 条。

新授权操作记录关联客户和当时的账号名称。历史记录保持不可修改，只按已有本地关系解析；无法确定的客户显示未关联，不根据操作者推测归属。操作者和客户姓名按当前资料展示。

数据库启动时仅为审计表补充可空字段和查询索引，不删除、回填或改写历史审计，现有不可更新/不可删除约束保持不变。

## 验证范围

HTTP 和浏览器回归使用隔离 SQLite、合成客户和本机提供方夹具。结果不代表真实提供方、真实支付、生产部署或用户验收。
