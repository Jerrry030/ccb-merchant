# 商户账号交付

[文档索引](README.md) · [管理员日常业务](ADMIN-WORKFLOWS.md) · [接口契约](API-CONTRACT.md)

## 范围

商户只销售、分配本站已经获得授权的账号服务。不接收供应商登录凭据，也不需要理解提供方如何取得或维护服务能力。

一个账号当前只交付给一位客户，并受返回的设备限制和有效期约束。一位客户可以持有多个账号。客户期限不能超过本站可交付期限。

## 商户管理员

1. 在「库存」读取当前可分配账号。
2. 选择账号和本站客户，确认交付期限。留空时使用接口允许的默认期限。
3. 使用读取到的账号版本提交交付。首次交付所需的客户登记由本站完成，不要求客户另外登录提供方。
4. 成功后检查客户、账号、期限和设备状态；未知结果保持待核对，不显示为成功。

已分配账号可以按当前授权版本延长客户期限或收回。收回确认前不能重新分配；历史交付记录不会改写给新客户。

### 当前库存与历史记录

- 默认展示「当前库存」。已释放、已到期或已明确超过到期时间的授权归入只读「历史记录」；释放状态优先保留为「已释放」。上游暂不可用、未知状态、缺少详情或无效到期时间仍留在当前库存供核对，不伪装成历史或可分配账号。
- 可分配和已分配统计仅基于当前筛选范围内仍有效的授权。历史记录不计入；有效期无法确认的记录也不计入。有效但上游暂不可用的已分配授权仍需管理，保留其客户占用统计。
- 历史列表展示「原授权到期」，只允许查看记录，不提供分配、延长、收回操作；记录详情不把实时额度或设备状态当成历史快照，也不虚构释放时间。
- 同名或同邮箱记录不合并。所有交付操作仍使用被选中的授权占用 ID 和修订号；这些 ID 不作为跨批次底层账号标识。
- 从客户的账号分区进入时，当前库存包含该客户关联的授权及未分配库存，历史只包含明确关联该客户的记录。上游未提供历史客户关联时，不推断归属，可通过「查看全部库存」核对原记录。
- 切换视图会保留客户筛选，刷新后仍停留在已选择的视图。

## 客户

1. 登录商户提供的本站地址，在「我的账号」核对已分配账号、期限和可用状态。
2. 从「开始使用」或账号卡片进入连接流程。按本站交付且已验证的客户端版本准备环境，使用页面生成的本站登录命令；不要把提供方地址或服务密钥填入终端。
3. 只确认自己刚发起的设备请求，核对设备信息后在页面确认，再回到终端选择账号并开始使用。
4. 在「我的设备」核对设备授权、账号选择和到期时间；已授权不代表实时在线。改名、清空选择、切换或撤销都使用本站页面。
5. 换机时先解除旧设备的账号选择或撤销连接，再确认新设备，不自动抢占。设备续期与客户账号续期分别处理。

无账号时先联系管理员完成分配，不要求先安装客户端或充值。客户端安装/更新成功也不等于真实运行接入已经验收，版本范围见[接口契约](API-CONTRACT.md)。

账号不可用、已到期、无库存和提供方不可达是不同状态。无账号时联系商户管理员，不要求先充值，也不虚构可用账号。

## 冲突与未知结果

保存原客户、账号、期限及版本，使用「核对分配结果」确认。不得更换请求标识、悄悄改选账号或重复收费来解决超时。

发生版本冲突时重新读取并确认。支付成功不等于交付已完成；交付失败也不自动证明可以退款。

## 验收

隔离测试验证交付、撤销、期限、版本冲突和未知结果。真实提供方联调必须使用获授权的资源另行执行，不以合成库存或模拟支付代替。


## 本店编号与批次

库存的“账号#…”是本站生成的持久化授权占用编号，不是提供方账号名；不同占用不合并，历史记录保留。具体交付、额度和批次恢复操作见 [管理员日常业务](ADMIN-WORKFLOWS.md)。

## 自有账号

「库存 → 管理自有账号」用于添加、重新授权、暂停/恢复和退出自己的账号。只在提供方确认就绪后进入库存。`source=owned` 且空持有到期代表无固定托管期限，不需要钱包余额或上级库存；分配给客户必须设置明确日期。一个客户可以同时持有多个具体账号。

暂停来源账号不等同收回客户授权；退出会停止使用并保留历史。上级及兄弟站点不能因转交而获得自用/销售权；每次请求仍经过原逐级路径。
