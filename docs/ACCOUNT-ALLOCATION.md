# 商户账号交付

## 范围

商户只销售、分配本站已经获得授权的账号服务。不接收供应商登录凭据，也不需要理解提供方如何取得或维护服务能力。

一个账号当前只交付给一位客户，并受返回的设备限制和有效期约束。一位客户可以持有多个账号。客户期限不能超过本站可交付期限。

## 商户管理员

1. 在「账号库存」读取当前可分配账号。
2. 选择账号和本站客户，确认交付期限。留空时使用接口允许的默认期限。
3. 使用读取到的账号版本提交交付。首次交付所需的客户登记由本站完成，不要求客户另外登录提供方。
4. 成功后检查客户、账号、期限和设备状态；未知结果保持待核对，不显示为成功。

已分配账号可以按当前授权版本延长客户期限或收回。收回确认前不能重新分配；历史交付记录不会改写给新客户。

### 当前库存与历史记录

- 默认展示「当前库存」。已释放、已到期或已明确超过到期时间的授权归入只读「历史记录」；释放状态优先保留为「已释放」。上游暂不可用、未知状态、缺少详情或无效到期时间仍留在当前库存供核对，不伪装成历史或可分配账号。
- 可分配和已分配统计仅基于当前筛选范围内仍有效的授权。历史记录不计入；有效期无法确认的记录也不计入。有效但上游暂不可用的已分配授权仍需管理，保留其客户占用统计。
- 历史列表展示「原授权到期」，只允许查看记录，不提供分配、延长、收回操作；记录详情不把实时额度或设备状态当成历史快照，也不虚构释放时间。
- 同名或同邮箱记录不合并。所有交付操作仍使用被选中的授权占用 ID 和修订号；这些 ID 不作为跨批次底层账号标识。
- 从客户管理进入时，当前库存包含该客户关联的授权及未分配库存，历史只包含明确关联该客户的记录。上游未提供历史客户关联时，不推断归属，可通过「查看全部库存」核对原记录。
- 切换视图会保留客户筛选，刷新后仍停留在已选择的视图。

## 客户

登录本站后从「开始使用」或账号卡片进入连接流程。首次确认设备后使用；换机时先撤销旧设备再连接新设备，不自动抢占。

账号不可用、已到期、无库存和提供方不可达是不同状态。无账号时联系商户管理员，不要求先充值，也不虚构可用账号。

## 冲突与未知结果

保存原客户、账号、期限及版本，使用「核对分配结果」确认。不得更换请求标识、悄悄改选账号或重复收费来解决超时。

发生版本冲突时重新读取并确认。支付成功不等于交付已完成；交付失败也不自动证明可以退款。

## 验收

隔离测试验证交付、撤销、期限、版本冲突和未知结果。真实提供方联调必须使用获授权的资源另行执行，不以合成库存或模拟支付代替。
